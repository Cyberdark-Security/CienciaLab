Esto muestra el uso de la biblioteca CienciaLab para dibujar gráficos con JavaScript en la línea de comandos del Terminal.

Este gráfico muestra una sola GraphLine. Sin embargo, se puede cambiar el estilo (color, ancho de línea, puntos o líneas) en cualquier momento, de modo que puede parecer que se están dibujando varios gráficos distintos.

Para borrar todos los puntos de la GraphLine:

  graphLine.reset();

Para dibujar un nuevo gráfico se usa el comando "plot". Esto agrega puntos a la GraphLine, con el valor de "x" variando entre los dos números dados.

  plot("x*x", -5, 5);

Se puede especificar el número de puntos dibujados como cuarto argumento de plot (el valor por defecto es 200). Para agregar puntos a la GraphLine en un color nuevo:

  graphLine.setColor("red");
  plot("-x*x", -5, 5, 50);

Para cambiar el área mostrada (los argumentos son izquierda, abajo, arriba, derecha)

  simView.setSimRect(new DoubleRect(-6, -30, 6, 30));

Para cambiar el ancho de línea o el modo de dibujo:

  graphLine.setLineWidth(2);
  plot("x", -10, 10);
  graphLine.setDrawingMode("dots");
  graphLine.setColor("black");
  plot("-x", -10, 10);

Para redibujar toda la GraphLine con un estilo distinto:

  graphLine.setColor('blue');
  graphLine.resetStyle();
  graph.reset();
