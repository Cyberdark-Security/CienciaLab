BlankApp le permite experimentar construyendo una simulación de cuerpo rígido mediante scripting. Ya cuenta con un ContactSim, LabCanvas, SimView, Terminal y otros objetos creados. A continuación se muestra un script de ejemplo para probar ingresándolo en el Terminal.

ELASTICITY=0.9;
SHOW_CLOCK=true;
Walls.make(sim,12,12,0.01);
var p=Shapes.makeBall(0.2,'fast_ball');
p.setMass(0.1);
p.setPosition(new Vector(-5, 0));
p.setVelocity(new Vector(200, 153));
p.setElasticity(0.9);
sim.addBody(p);
displayList.findShape(p).setFillStyle('green');
sim.saveInitialState();
app.addStandardControls();

También se puede proporcionar un script en la cadena de consulta de la URL (después del signo de interrogación) de esta página. Por ejemplo, la siguiente URL contiene el script anterior.

#TOP_DIR/sims/engine2D/BlankApp-es.html?ELASTICITY=0.9;
SHOW_CLOCK=true;Walls.make(sim,12,12,0.01);var%20p=Shapes.makeBall(0.2,'fast_ball');
p.setMass(0.1);p.setPosition(new Vector(-5,0));p.setVelocity(new Vector(200,153));
p.setElasticity(0.9);sim.addBody(p);displayList.findShape(p).setFillStyle('green');
sim.saveInitialState();app.addStandardControls();

Debido a la codificación por porcentaje (percent-encoding) debemos sustituir en la URL:

  • %20 para espacio
  • %22 para comilla doble
  • %27 para comilla simple

Consulte esta tabla de codificación de caracteres para saber qué otros caracteres deben codificarse con el signo de porcentaje.
